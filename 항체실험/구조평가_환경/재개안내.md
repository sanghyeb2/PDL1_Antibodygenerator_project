## 이번에 해결/확인한 사항

- 이전 Colab 임시 디스크가 소실되어 공통 항원 결과를 다시 계산해야 했다. 기존 로컬 MSA/입력은 재사용했다.
- 설치된 ColabFold 1.6.3에서 `--recompile-padding`은 정수다. `1.1` 오류를 작은 CLI로 재현하고 기본값 **10**의 정상 파싱을 확인했다.
- 동기 대기 루프를 중단하자 기존 batch도 SIGINT로 종료됨을 확인했다. 그 전에 완료된 `MAGE_0910`을 보존했고, 이후 계산은 별도 session + 비동기 대기로 재개했다. 이미 완료된 항원/첫 Fv는 재예측하지 않았다.
- 파일 다운로드와 로컬 import 완료를 실제로 확인했다. 항원 및 첫 Fv는 Colab 세션이 사라져도 로컬에서 재사용 가능하다.

## 이어서 진행 / 일시정지할 때

1. 기존 Colab 탭에서 현재 batch의 실행 상태/완료 후보 수부터 확인한다. **동일 배치를 중복 실행하지 않는다.**
2. 완료된 결과 ZIP을 내려받아 `import-colab --archive <ZIP>`으로 검증·반영한다. 진행 중 폴더를 읽어 만든 ZIP은 다음 후보 완료 후 다시 수집해야 할 수 있다.
3. 일시정지 요청 시 노트북 대기만 중단해도 별도 session의 계산은 계속될 수 있다. 기록된 PID와 실제 프로세스를 확인하고, 완료 파일을 보존한 후 해당 작업만 중지한다. 모든 Python/GPU 프로세스를 일괄 종료하지 않는다.
4. 전체 구조 수집 후 공통 도킹 예산을 기록하고 HADDOCK3 → 클러스터/접촉면 → PRODIGY → 후보 표/그림을 진행한다.
5. 대조군 소규모 redocking은 실제 접촉 복원에 실패했으므로 본 비교 검증으로 사용하지 않는다. 개인 `실험결과.pptx`는 건드리지 않는다.

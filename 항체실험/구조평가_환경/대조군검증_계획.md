# 대조군 도킹 검증 — 2026-11-19

목표: 실험 복합체의 알려진 자세를 회복하는지 확인하고, 입력 구조 오차와 탐색·순위 선정의 영향을 구분한다. 사용자가 승인한 실험 구조 재도킹 및 예측 구조 비교 방향을 구체화한 실행 계획이다.

- 기존 main 42쌍 결과는 변경하지 않는다. 코드 진입점은 `구조평가.py` 하나를 유지한다.
- 5X8L/5X8M의 두 대조군 각각에 실험 Fv/PD-L1 구조와 동일 잔기 범위의 ColabFold 구조를 사용한다. 원래 main의 전체 ECD 결과는 별도 조건으로 표시한다.
- 원자 좌표는 각 입력에서 가져온다. 예측 입력을 실험 좌표로 대체하지 않는다. 실험 항원과 예측 항원의 서열 차이도 기록한다.
- CDR 접근성 및 항원의 전체 접근 가능 표면만 탐색 제약에 사용한다. 정답 접촉·자세는 평가 전용이다. 결합 상태에서 추출한 구조의 재도킹은 쉬운 조건이며 독립적인 생성 성능 검증이 아니다.
- 각 실행: CPU 6개, seed 42, rigidbody 1000 → flexref 100 → emref → 기존 클러스터/순위. 네 실행을 순차 처리한다. 추가 시드 반복은 하지 않는다.
- HADDOCK 공식 CAPRI 평가로 emref의 전체 100개를 평가한다. Fnat(5 Å), iRMSD(10 Å 인터페이스), LRMSD, DockQ를 기록한다. 기존 4 Å 접촉 recall과 Fnat을 혼동하지 않는다.
- 점수 상위 1/5/10 및 전체 포즈 중 최상 DockQ를 나눠 기록한다. 정답으로 찾은 최상 포즈는 진단용이며 배포 가능한 순위가 아니다.
- 동일 구조는 DockQ≈1, 항체만 멀리 옮기면 Fnat=0 및 낮은 DockQ가 나오는지 검사한다. 예측 입력의 잔기 대응과 좌표 보존을 검사한다.
- 결과 표와 과학용 정적 그림을 자동 저장한다. 중단 시 단계/로그/원본을 보존하며 완료된 실행은 해시를 검사해 재사용한다.

실행 단계:

1. [x] 잔기 범위 매칭 및 공식 CAPRI 평가의 의미 있는 검사 → 최소 기능 구현.
2. [x] 네 조건 준비·해시/설정·출처 기록, 평가만 먼저 기존 main 대조군에 적용.
3. [x] 6개 병렬 독립 세션 실행, 실제 작업/시드/로그 확인.
4. [ ] 각 조건 완료 후 자동 분석·비교 그림, 기존 결합면 복원 한계 유지.

해석: 실험 구조에서도 올바른 포즈가 없다면 탐색·제약/모델링을 점검한다. 올바른 포즈가 있으나 낮게 순위화되면 점수/선정 문제를 검토한다. 예측 입력에서만 악화되면 입력 오차의 영향과 항원 서열 차이를 함께 검토한다. 두 조건만으로 단일 원인을 확정하지 않는다.

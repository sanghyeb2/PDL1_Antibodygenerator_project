# 대조군 검증 후속 계획 — 2026-11-20

현재 상태: **1·2단계 후처리 완료(2026-11-20), 3단계 새 도킹 미시작**. 기존 main 42쌍과 추가 대조군 4조건은 완료됐으며 모두 보존한다.

## 확인된 근거

- 실험 구조 입력의 전체 100개 중 최상 DockQ: atezolizumab 0.912812, durvalumab 0.817419.
- 잔기 범위를 맞춘 ColabFold 입력: 각각 0.166906, 0.079485. 차이는 입력 구조의 영향을 의심할 근거지만, 항원 한 위치 GLU/GLN 차이와 접근성 기반 제약 차이도 있어 구조 단독 원인으로 확정할 수 없다.
- atezolizumab 실험 입력의 `emref_2.pdb`: HADDOCK 점수 -154.3448, 점수 순위 1, Fnat 0.92, iRMSD 0.667 Å, LRMSD 1.102 Å, DockQ 0.912812. `5_clustfcc/clustfcc.tsv`의 cluster_id는 `-`이다. 이 포즈가 미분류 상태로 선택 단계에서 제외된 사실을 확인했다. 최종 최상 클러스터 상위 4개 중 최상 DockQ는 0.020636이다.
- 즉 이 사례에서는 점수 자체가 좋은 포즈를 1위로 올렸지만, 클러스터 기반 필터가 이를 보존하지 못했다. 모든 후보에 동일 원인이 적용된다고 일반화하지 않는다.

## 1단계 — 새 도킹 없이 선정 방식부터 점검

기존 정제·최소화 결과 600개를 재사용한다. CNS 재실행이나 새 seed 반복은 하지 않는다.

1. 전체 포즈 → FCC 클러스터/미분류 → 최종 선택의 추적표를 만든다. 각 포즈의 원래 emref 이름, 점수, cluster_id/크기, 선택 여부를 연결한다. 미분류는 단일 포즈라는 뜻으로 단정하지 않고 최소 인원 기준 등의 이유를 확인한다.
2. 다음 세 규칙을 사전에 고정해 비교한다.
   - **기존 규칙:** 최상 클러스터 상위 4개.
   - **전체 점수 기준:** 클러스터 여부와 무관한 점수 상위 5개.
   - **다양성+구제:** 상위 5개 클러스터의 대표 1개씩과 전체 점수 상위 5개의 합집합(최대 10개, 중복 제거). 미분류 고득점 포즈도 포함하되 미분류/낮은 수렴도 표시를 유지한다.
3. 선정 개수가 다르므로 동일 후보 수 예산의 Recall@K/최상 DockQ도 함께 비교한다. 크기가 큰 후보 집합이 유리한 것을 방법 개선으로 혼동하지 않는다. 기준 구조는 평가에만 사용한다.
4. 결과물: 점수–DockQ 산점도(클러스터/미분류 색), 선정 포즈 표시, 포즈 보존 흐름, 고정된 후보 수별 복원 비교. DockQ로 후보를 직접 고르는 규칙은 만들지 않는다.
5. 필요할 때만 기존 좌표의 FCC 재클러스터링으로 min_population(4/2), cutoff(0.6/0.5)의 제한된 민감도 분석을 한다. 이를 개발용 분석으로 표시하고 두 대조군에 최적화한 임계값을 검증 완료로 발표하지 않는다.

판단: 고품질 포즈가 존재하지만 선정에서 소실되는 경우, 구제/다양성 보존을 우선한다. 전체 포즈에도 좋은 구조가 없는 조건은 선정 방식만 바꿔 해결됐다고 하지 않는다.

## 2단계 — 입력 구조 감사, 비용이 적은 분석 우선

새 구조 예측에 앞서 기존 구조를 정렬·비교한다.

- VH/VL 각각의 공통 backbone 정렬, framework 정렬 후 CDR1/2/3 오차, VH 정렬 후 VL 상대 배치 차이를 확인한다.
- PD-L1의 동일 관측 잔기만 정렬해 결합면 loop/side-chain 차이와 결손 원자·잔기, 말단, 사슬/번호 대응을 점검한다.
- pLDDT/PAE는 오류 점검의 보조 정보로 사용한다. 높은 신뢰도가 정확한 결합 자세나 높은 친화도를 보장한다고 해석하지 않는다.
- GLU/GLN 차이, 수소/양성자화·전처리 차이, 접근성에서 얻은 실제 AIR 잔기 집합의 차이도 목록화한다. 공식 전처리 후 실제 비교 가능한 차이를 구분한다.
- 대표 구조 중첩 그림과 오류 요약 JSON을 만든다. 이 단계까지는 기존 40개 생성 항체를 재도킹하지 않는다.

## 1·2단계 완료 후 확인된 추가 통제 사항

- 같은 4개 예산에서 atezolizumab 실험 구조의 클러스터 기준 최상 DockQ0.0206 대 전체 점수/구제 기준0.9128을 확인했다.
- 예측 조건의 정제100개에는 허용 품질 포즈가 없었다. 초기1000개 전체 품질은 아직 평가하지 않았다.
- atezolizumab의 H100/L212 히스티딘 양성자화·전하가 입력에 따라 달랐다. 같은 총 원자 수가 화학 조건의 동일성을 보장하지 않았다.
- 따라서 아래 교차 실험에는 동일 서열·항원·AIR뿐 아니라 사전 고정한 동일 양성자화/화학 타입 정책을 추가한다. DockQ를 보고 양성자화 설정을 고르지 않는다.
- 상세 결과: `공유결과/대조군점검_20261120/README.md`.

## 3단계 — 필요성이 확인되면 소규모 교차 실험

먼저 각 대조군에서 **실험 PD-L1을 공통으로 고정**하고 실험 Fv 대 예측 Fv를 비교한다. 항체 서열은 동일하며 같은 항원 서열/좌표를 사용하므로 항원 GLU/GLN 혼동을 피한다.

- 양쪽 입력에 공통으로 적용 가능한 동일 AIR 잔기 집합을 사전에 정한다. 예측마다 제약을 다시 정해 좌표와 제약 효과가 섞이지 않게 한다.
- 각 대조군의 실험 Fv+실험 PD-L1, 예측 Fv+실험 PD-L1을 비교한다(최대 4개 실행). 기존 실험 입력 결과와 설정·입력·제약 해시가 모두 같을 때만 기존 결과를 재사용한다. 제약이 바뀌면 대조군 baseline도 새 조건으로 계산한다.
- 예측 Fv 조건에서만 악화되면 항체 구조/도킹과의 상호작용을 우선 검토한다. 성공/실패만으로 단일 원인을 단정하지 않는다.
- 항원 영향을 더 분리해야 할 경우에만 동일 서열 PD-L1의 예측 구조를 준비하고 실험/예측 Fv × 실험/예측 항원의 2×2로 확장한다. 두 대조군 전체 최대 8개 조합이며, 앞 단계와 동일한 조건은 재사용한다.
- 각 실행은 seed42, CPU6, 1000/100 예산 유지. 추가 seed 반복과 전체 40개 재실행은 별도 근거가 생기기 전까지 하지 않는다. 새 구조 생성·동일 서열 전처리 방법은 실제 실행 전에 고정·기록한다.

## 적용과 검증의 경계

두 대조군은 방법 개발에 사용됐다. 이를 보고 선정 규칙을 정하면 같은 두 사례의 개선은 독립 검증이 아니다. 가능한 경우 설정 조정에 쓰지 않은 항체–항원 실험 복합체로 고정한 규칙을 평가한다. 없다면 파일럿 개선으로만 보고한다.

고정한 선정 규칙을 기존 MAGE/LoRA 40쌍에 적용할 때는 먼저 저장된 포즈를 재분석해 `v2`로 별도 저장한다. v1을 덮어쓰지 않는다. 새 계산이 필요한 경우 대조군에서 확인한 원인에 맞춰 제한된 후보부터 시행한다. DockQ 정답이 없는 생성 항체의 선정에 DockQ를 사용하지 않으며, 높은 도킹 점수/PRODIGY 추정치만으로 실제 결합력 향상을 주장하지 않는다.

## 시간과 우선순위

1단계와 2단계가 우선이며 주로 후처리·구조 분석이다. 새 도킹이 필요한 3단계는 대조군 수에 따라 별도의 수 시간 계산이 될 수 있다. 실제 비용은 첫 교차 조건의 측정치로 갱신한다. 사용자가 승인한 1·2단계는 기존 자료로 완료했다. 3단계 신규 도킹은 시작하지 않았다.

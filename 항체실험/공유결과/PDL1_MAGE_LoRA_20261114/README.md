## 원시 기록과 재사용

- `MAGE/`, `LoRA/`: 모든 생성 시도의 raw token IDs·원시 문자열·파싱 결과·실패 사유, 생성 설정, 실행 버전 기록. `raw_candidates.json`은 모델별 1,000회 전체다.
- `분석/generated_annotated.json`, `known106_annotations.json`: 생성 서열과 알려진 양성의 주석 결과.
- `분석/all_metrics.json`: 모델별 모든 시도의 거리·유사도·단계 통과 여부. 값의 원시 기록용이며, 처음에는 CSV와 그림을 보는 편이 쉽다.
- `분석/oasis_pair_cache.json`: 공식 BioPhi에서 이미 얻은 점수. `oasis_settings.json`은 DB 검증 기록·버전·10% subject 기준을 보존한다.
- `분석/analysis_provenance.json`: train85/known106/원본 학습 18,507쌍의 역할과 도구 버전, 코드·데이터 해시.
- `공유파일_목록.json`: 공유한 원본 산출물의 크기와 SHA-256. `실행코드_원본기록.zip`은 실행 당시 코드의 원래 바이트를 보관한다. 평소 편집·실행은 저장소의 `항체실험/MAGE.py`, `항체실험/LoRA.py`를 사용한다. Git의 소스 줄바꿈 정규화로 실행 당시 파일 hash와 다를 수 있다.

그림·FASTA·CSV는 환경 설치 없이 열 수 있다. Python 환경이 준비되어 있으면 저장소 루트에서 **기존 점수만 사용한 간단한 그림**도 다시 만들 수 있다.

```powershell
python 항체실험/LoRA.py --mode preview --campaign-dir 항체실험/공유결과/PDL1_MAGE_LoRA_20261114
```

위 명령은 모델 추론·ANARCI 실행·OASis 재계산을 하지 않는다. 완료된 전체 분석 그림은 위 PNG/SVG를 사용한다. 새 생성 실험은 새로운 `생성결과` 폴더를 사용한다.

## 해석 범위와 다음 단계

OASis는 사람 레퍼토리 유사성 지표다. 선택한 20쌍은 계산상 후보이며 PD-L1 결합이 확인된 항체가 아니다. 학습 신규성은 train85와 원본 MAGE 학습 자료에 대해 따로 계산했고, known106은 알려진 양성과의 근접성 및 후보 선별 기준이다. known106에는 검증셋 21쌍도 포함된다.

추가 테스트·코드 리뷰와 구조/도킹·실험적 결합 검증은 추후 진행한다. 원본 대용량 MAGE 가중치, OASis DB, Python 환경, 수천 개의 작업용 ANARCI 캐시는 포함하지 않는다. 분석 재실행 환경은 [시작안내](../../시작안내.md), 전체 진행 상황은 [프로젝트 README](../../../README.md)를 따른다.

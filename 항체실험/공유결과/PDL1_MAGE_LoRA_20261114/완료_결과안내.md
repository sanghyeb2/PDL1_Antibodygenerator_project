# 생성 및 서열 분석 완료

원본 MAGE와 LoRA 각각 총 1,000회 생성했다. 기존 배치는 재사용했고 각 배치의 시드와 설정은 모델별 generation_settings.json에 남겼다.

- MAGE: 기본 검사 991쌍 → OASis ≥0.70 735쌍 → 추가 선별 672쌍 → 최종 20쌍.
- LoRA: 기본 검사 997쌍 → OASis ≥0.70 849쌍 → 추가 선별 747쌍 → 최종 20쌍.

분석/생성항체_주요분석.png 및 .svg가 전체 그림이고, 생성항체_보충분석.png/.svg가 보충 그림이다. LoRA_최종후보.fasta와 MAGE_최종후보.fasta에 선택된 VH/VL이 있다. 전체 시도별 기록은 전체후보_단계별지표.csv를 확인한다.

추가 테스트·코드 검토 및 실제 결합력/도킹 검증은 수행하지 않았다. 여기의 선택은 서열 특성에 근거한 계산 후보 선별이다. 이전 중간미리보기·중간저장 문서는 당시의 기록이며 최신 결과는 이 문서와 분석/결과_읽는법.md를 따른다.
